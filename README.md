# VIVER AR

Android Chrome에서 손목에 시계를 착용해 보는 전체 화면 웹 프로토타입입니다.

1. 카메라 시작을 누르고 카메라 권한을 허용합니다.
2. 손등과 손가락을 화면에 담고 약 2초간 멈춥니다.
3. 방향을 다시 맞추려면 오른쪽 아래 **손등 재추적**을 누릅니다.

착용 중에는 카메라와 시계, 재추적 버튼만 표시됩니다. 처음 연결과 재추적 때 안내를 잠시 표시합니다. 전체 화면을 지원하지 않으면 웹페이지 영역을 채웁니다. 다른 앱으로 이동하면 카메라를 종료하며, 돌아온 뒤 다시 시작할 수 있습니다.

카메라 영상은 기기에서 처리합니다. 서버로 영상이나 관절 좌표를 전송하지 않으며 진단 기록도 자동으로 시작하지 않습니다. 단일 카메라의 추정이므로 빠른 회전·가림·손목 꺾임에는 오차가 남을 수 있습니다.

## 개발

Node.js 20 이상에서 실행합니다.

```sh
npm ci
npm test
npm run build:share
```

배포 결과는 `dist-share/`입니다. `npm start`는 설정이 포함된 개발 화면을 열고 `/share.html`에서 공유 화면을 확인할 수 있습니다. GitHub Actions는 테스트 후 공유 화면을 GitHub Pages로 배포합니다.

버전 0.7.13. 추적과 시계 모델은 검증 기준 0.7.12를 유지합니다. 자동 검사 98개를 통과했고 카메라 시작·재추적·권한 거부·화면 전환과 모바일 배치를 통제된 입력으로 확인했습니다. 실제 기기의 카메라 성능과 추적 정확도를 보장하는 검사는 아닙니다.
